# Humanizer PRO modes

## Stealth

Use for general-purpose text such as emails, posts, scripts, and everyday business writing. It varies sentence structure and tone while preserving meaning.

Optional styles:

- `creative`: More expressive rhythm and word choice.
- `journalistic`: Direct, clear, information-led prose.
- `professional`: Polished workplace and client-facing prose.

If the user delegates the choice without naming a mode, use Stealth. Do not infer a style unless the request clearly implies one.

## Academic

Use for formal drafts, research notes, and scholarly-style writing the user is allowed to revise. Preserve citations, qualifications, technical terms, and factual scope. Do not imply that the output satisfies an institution's authorship or disclosure rules.

## SEO

Use for marketing pages, product copy, and blog drafts where keywords and search intent should remain intact. Preserve supplied keywords, headings, links, and claims. Do not add unsupported claims or keyword stuffing.

## Selection examples

| Request | Mode |
| --- | --- |
| “Make this customer email sound natural; choose for me.” | Stealth |
| “Rewrite these research notes formally.” | Ask Stealth or Academic unless the user already delegated the choice. |
| “Humanize this landing page but keep the target keywords.” | SEO |
| “Use a newsroom voice.” | Stealth with Journalistic style |
