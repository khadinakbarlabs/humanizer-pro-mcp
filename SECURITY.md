# Security Policy

Report security issues privately by emailing `support@texthumanizer.pro`.

Please do not open public GitHub issues for vulnerabilities, OAuth callback issues, account access issues, or suspected data exposure.

The public repository contains the Agent Skill, plugin manifests, connector metadata, assets, tests, and validation scripts. It contains no hosted-service credentials or proprietary backend code. The hosted service is operated at `https://texthumanizer.pro`.

Before reporting an issue, do not paste access tokens, OAuth codes, private text, billing records, or account identifiers into a public issue. The automated release check rejects common credential formats and personal filesystem paths.
